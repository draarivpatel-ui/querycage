# Changelog

## 1.0.0

Initial local release candidate.

- Strict zero-dependency query-string parser and auditor with adversarial red-team hardening.
- HTTP Parameter Pollution defenses and configurable duplicate policies.
- Prototype pollution firewall with null-prototype output.
- NoSQL operator and secret-in-query detection.
- Sparse array, malformed bracket, encoding, Unicode control, depth, and byte-cap defenses.
- REST pagination, sort, and sparse field projection auditing.
- Deterministic sanitization and canonical serialization.
- Strict, REST API, search, and OAuth callback policy presets.
- ESM, generated CommonJS, TypeScript declarations, CLI, examples, tests, and CI.
